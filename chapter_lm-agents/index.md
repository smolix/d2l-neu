# Agents and Tool Use
:label:`chap_lm_agents`

The reader has prompted a model, fine-tuned it and trained it with a verifier; a model that only emits text can be asked a question, while a model that emits actions can be given a job. This chapter turns the models of Chapters 1 to 9 into agents: systems that call a tool, read what comes back, run code and keep going over many turns.
