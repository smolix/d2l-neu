**Idea:** A cheap drafter proposes several tokens and the target verifies them in one pass that costs about one weight read, and the accept-or-resample rule leaves the output distribution exactly the target's.
**Opening:** The reader has 12.1's decoder, which reads every weight for every token, and the `sec_kv-cache` exercise showing that a pass over five tokens costs about as much as a pass over one while the step is bandwidth-bound. The opening cell prints, for Qwen3-4B at batch 1, the measured time of a one-token step and of a five-token verification pass on the same graph machinery, nearly equal. The question is which five tokens to verify, and the closing question is when the drafter's own cost eats the gain.
**Teaches:**
- The round: draft `γ` tokens from the drafter's distribution `q`, run the target once over `[y, x_1, …, x_γ]`, accept `x_i` with probability `min(1, p/q)`, on the first rejection sample from the normalized `max(p − q, 0)`, and take one bonus token when all are accepted; what sits in each cache after the round and how `rollback` restores it.
- Exactness: the emitted token has law `p`, and the acceptance probability `Σ min(p, q) = 1 − TV(p, q)` is the best any exact rule can do; both `p` and `q` must be the processed distributions (temperature, top-k, top-p) of the same sampler.
- Expected tokens per target call `(1 − α^{γ+1})/(1 − α)` for a constant acceptance `α`, and `Σ_i Π_{j ≤ i} α_j` in general; acceptance by position, task and sampler.
- A wall-clock model with the draft's cost ratio `c`, the target's wider pass, and the batch: `S(γ) = E[N]/(1 + γ c)` in the bandwidth-bound idealization, the interior optimum in `γ`, and the rule that some `γ` helps only if `α` exceeds `c`.
- Where speculation loses, each with its fix: an eager drafter (graph it), a batch past the ridge (lower `γ` or switch off), a long context with a full-cache drafter (cap the drafter's context), a drafter whose acceptance falls below `c` (a better-aligned drafter, 12.5); n-gram drafting from the prompt as the free baseline that wins when text repeats.
**Derivation:** Exactness and the expected accepted length. For one position, `P(Z = x) = min(p, q) + (1 − β) · max(p − q, 0)/(1 − β) = p` with `β = Σ min(p, q)`; recursively over positions with the bonus token. Then `E[N] = Σ_{i=0}^{γ} α^i`. Smallest case: `p = (0.5, 0.3, 0.2)`, `q = (0.2, 0.5, 0.3)`: `β = 0.7`, residual `(1, 0, 0)`, and the law of `Z` recovers `p` by hand.

Both distributions must come from `processed_probs` with the same settings; a deliberate-mismatch cell shows the wrong output. Count tokens per target call, not per draft call; include draft and accept time in `S`; measure against the graphed target-only decoder, never an eager baseline. Recurrent or hybrid targets (Qwen3.5) cannot roll back a rejected suffix by decrementing a position; 12.5 returns to this.
