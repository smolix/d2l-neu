**Idea:** Splitting a weight matrix across GPUs along one dimension costs exactly the collective that restores the dependence the split broke, and the forward and backward collectives come in conjugate pairs.
**Opening:** The reader solved the exercise `ex_mgp-tensor` of `sec_multi_gpu_concise`: the MLP's first weight split by columns and the second by rows, one all-reduce for the sum, and a count of bytes against data parallelism. One concrete example: Qwen3-8B's attention and MLP on eight GPUs, every layer paying four all-reduces of the activation while the computation on each GPU shrinks eightfold; whether the layer is faster depends on the link, not on the memory saved. The open question: which operator pairs make the gradients correct, which parameters need an extra reduction, and where the split should stop.
**Teaches:**
- Column- and row-parallel linear layers, the bias handled once, and the conjugate operators f (identity forward, all-reduce backward) and g (all-reduce forward, identity backward) as a derived rule, with the counter-example where deleting f's backward leaves the input gradient wrong by exactly the off-rank terms.
- Attention by heads: query heads split, KV heads split when divisible by the degree and replicated otherwise, with the replicated gradients summed over the replica group; the rule for replicated parameters (norm weights, QK-norm) in one sentence: an all-reduce iff each rank's loss depends on the parameter through a different part of the computation.
- Sequence parallelism: the all-reduces become a reduce-scatter and an all-gather over the sequence dimension, the norms and dropout are sharded by tokens, the bytes are the same and the activation memory falls; DTensor placements (`ColwiseParallel`, `RowwiseParallel`, `SequenceParallel`, `loss_parallel`) as the library form.
- Bytes per layer against FLOPs per layer, the communication-to-compute ratio, and why tensor parallelism stays inside the NVLink domain; what tensor parallelism buys besides memory (smaller logits, smaller weight reads, a smaller global batch for an overlapped step).
**Derivation:** The conjugate operators and the ratio (blueprint ch06 6.3 D1, D3). For Z = phi(X A) B with A split by columns and B by rows, rank i computes Z_i = phi(X A_i) B_i and the forward sum is an all-reduce g whose backward is the identity, while X feeds every branch, so the gradient with respect to X is a sum over ranks: f's backward is an all-reduce. Per layer and microbatch each GPU moves 8 ((t-1)/t) b s d e wire bytes (four ring all-reduces of b s d elements) against 6 b s P_L / t FLOPs, so rho_TP = (4/3)(t-1) d e eta F / (P_L beta), independent of b and s. Smallest numeric case: Qwen3-8B with P_L about 193M, d = 4,096, e = 2, t = 8, eta F = 200 TFLOP/s and the NVSwitch row's beta gives a ratio the cell prints and compares with 5.6's `axis_ratio`, and the same t across a NIC twenty times slower multiplies it by twenty.
