# Further Reading
:label:`sec_transformers-further-reading`

The architectures built in this chapter share a common design: a pre-norm residual stream (:numref:`sec_transformer-block`), causal or bidirectional multi-head attention (:numref:`sec_gpt`, :numref:`sec_transformer`), a key--value cache compressed across heads, tokens, or channels (:numref:`sec_kv-cache`), and feed-forward layers scaled either densely (:numref:`sec_scaling-laws`) or through sparse expert routing (:numref:`sec_moe`). This section surveys important architectural variations and research directions that build on these foundations.

## Normalization Placement and Residual Stream Variants

Pre-norm (`RMSNorm` before each sublayer) is the default in most modern Transformers because it preserves an unattenuated identity path from the output back to the first layer (:numref:`sec_transformer-block`). In very deep models or long FP16/BF16 training runs, however, an unnormalized residual stream can accumulate large activation norms across depth, while attention score magnitudes can drift upward until softmax saturates. Two families of refinements address this (:numref:`fig_norm-taxonomy`):

![Four ways to place normalization around a sublayer $f$: (a) Post-LN normalizes the residual stream itself; (b) Pre-LN normalizes only the sublayer input; (c) Peri-LN (Sandwich-LN) normalizes both the sublayer input and the sublayer output before adding back to the stream; (d) QK-Norm adds per-head RMSNorm to queries and keys inside attention.](../img/mdl-transformers-norm-taxonomy.svg)
:label:`fig_norm-taxonomy`

- **Sublayer output normalization (Sandwich-LN / Peri-LN) and post-norm variants.** Normalizing both the input and the output of each sublayer ($x + \operatorname{Norm}(f(\operatorname{Norm}(x)))$) bounds the magnitude of each residual update while keeping the identity skip connection intact, a pattern used in CogView :cite:`Ding.Yang.Hong.ea.2021` and Gemma 2/3 :cite:`Gemma.Team.2024,Gemma.Team.2025`. OLMo 2 :cite:`OLMo.2025` instead moves the RMSNorm to the output of each sublayer ($x + \operatorname{Norm}(f(x))$) and combines it with QK-Norm, bounding residual stream growth without gating the identity path through a post-addition normalization.
- **Query--key normalization (QK-Norm).** Applying RMSNorm to queries and keys per head before computing $QK^\top / \sqrt{d_h}$ (:numref:`subsec_qk-norm`) bounds the pre-softmax logits by Cauchy--Schwarz regardless of residual stream growth :cite:`Henry.Dachapally.Pawar.ea.2020,Dehghani.Djolonga.Mustafa.ea.2023`. It is standard in ViT-22B, Gemma 3, Qwen3, and OLMo 2.
- **Normalization-free and soft-capped architectures.** DeepNorm :cite:`Wang.Ma.Dong.ea.2024` scales the residual branch of a Post-LN block by an explicit depth-dependent constant $\alpha = (2L)^{1/4}$ while down-scaling initialization by $\beta = (8L)^{-1/4}$, stabilizing Post-LN Transformers to 1,000 layers. Alternatively, Gemma 2 bounds attention and final logits via smooth tanh soft-capping ($c \tanh(z / c)$), though QK-Norm largely supersedes attention logit soft-capping in newer models.

## Feed-Forward Networks and Activation Functions

The original Transformer used a two-matrix ReLU feed-forward network with intermediate width $d_{\textrm{ff}} = 4d$ :cite:`Vaswani.Shazeer.Parmar.ea.2017`. GPT-2 and BERT replaced ReLU with GELU :cite:`Hendrycks.Gimpel.2016`. Following :citet:`Shazeer.2020`, almost all modern language models use gated linear units :cite:`Dauphin.Fan.Auli.ea.2017`—either **SwiGLU** (SiLU gate) or **GeGLU** (GELU gate)—with intermediate width $d_{\textrm{ff}} \approx \frac{8}{3}d$ rounded to a hardware-friendly multiple of 128 or 256 so that the three projection matrices ($W_{\textrm{gate}}, W_{\textrm{up}}, W_{\textrm{down}}$) match the $8d^2$ parameter and FLOP budget of an un-gated $4d$ FFN (:numref:`sec_transformer-block`). At extreme widths, **parallel Transformer blocks** (PaLM :cite:`chowdhery2022palm`, ViT-22B :cite:`Dehghani.Djolonga.Mustafa.ea.2023`) compute attention and the FFN in parallel from the same normalized input ($x + \operatorname{Attn}(\operatorname{Norm}(x)) + \operatorname{FFN}(\operatorname{Norm}(x))$), allowing the input projections of attention and the FFN to be fused into a single large matrix multiplication.

## Long-Context Inference and Cache Compression

Because decoding is memory-bandwidth bound (:numref:`subsec_kv-cache-prefill-decode`), reducing key--value cache traffic is central to efficient serving:

- **Grouped-query and multi-head latent attention.** Multi-query attention (MQA) :cite:`Shazeer.2019` and grouped-query attention (GQA) :cite:`Ainslie.Lee-Thorp.Jong.ea.2023` share key and value heads across groups of query heads (:numref:`sec_kv-cache-reduction`). **Multi-head latent attention (MLA)**, introduced in DeepSeek-V2 and DeepSeek-V3 :cite:`DeepSeek-AI.2024`, generalizes low-rank KV compression (:numref:`subsec_kv-cache-low-rank`) by projecting keys and values jointly into a single low-dimensional latent vector $c_t^{\textrm{KV}} \in \mathbb{R}^{d_c}$ ($d_c \ll H d_h$) cached in memory, while pairing it with a decoupled low-dimensional RoPE key vector so rotary position encodings remain compatible with weight absorption during decoding.
- **Sliding windows, attention sinks, and hybrid stacks.** Retaining the initial prompt tokens alongside a rolling window of recent tokens (**StreamingLLM** :cite:`Xiao.Tian.Chen.ea.2024`, :numref:`subsec_kv-cache-sinks`) preserves generation quality during streaming inference because the softmax denominator absorbs excess probability mass on the initial "sink" tokens. Many recent architectures (Gemma 3, gpt-oss) interleave several local sliding-window attention layers with one full global causal attention layer every 4–6 blocks, or interleave attention layers with linear-time state space / recurrent layers (:numref:`chap_modern_rnn`).
- **Speculative decoding.** Because verifying $m$ candidate tokens in parallel has nearly the same memory-bandwidth cost as decoding a single token (:numref:`subsec_kv-cache-prefill-decode`), **speculative decoding** :cite:`Leviathan.Kalman.Matias.2023,Chen.Borgeaud.Irving.ea.2023` uses a fast draft model (or extra multi-token prediction heads attached to the target model) to propose $m$ tokens and verifies them in a single target-model forward pass via a rejection-sampling rule that preserves the exact target distribution.

## Encoders, Cross-Attention, and Vision Backbones

- **Bidirectional encoders and retrieval.** While causal decoders dominate open-ended generation, bidirectional encoders (:numref:`sec_transformer`) remain the workhorse for dense text embeddings, reranking, and token-level classification. RoBERTa :cite:`Liu.Ott.Goyal.ea.2019` and DeBERTa :cite:`He.Liu.Gao.ea.2021` refine BERT's masked language modeling pretraining recipe, while ModernBERT :cite:`Warner.Chaffin.Clavie.ea.2024` brings the modern pre-norm, RoPE, SwiGLU, and unpadded FlashAttention stack to bidirectional encoders.
- **Vision Transformers and hierarchical hybrids.** Training ViTs effectively at moderate data scales relies on strong data augmentation and regularization (DeiT :cite:`touvron2021training`), self-supervised masked patch prediction (MAE :cite:`he2022masked`) or self-distillation (DINOv2 :cite:`Oquab.Darcet.Moutakanni.ea.2024`), and 2D rotary position embeddings. For dense prediction tasks (detection, segmentation) requiring multi-scale feature maps, Swin Transformers :cite:`liu2021swin` restrict self-attention to shifted local 2D windows across a hierarchical pyramid, while ConvNeXt :cite:`liu2022convnet` transfers Transformer block design choices back into pure depthwise-separable convolutional networks.

## Scaling Laws and Mixture-of-Experts Design

- **Compute-optimal vs. inference-aware scaling.** :citet:`kaplan2020scaling` first established power-law scaling of language model cross-entropy loss with model size $N$, dataset size $D$, and compute $C$. :citet:`hoffmann2022training` (Chinchilla) showed via IsoFLOP curves that training loss is minimized at fixed pretraining compute when $N$ and $D$ scale in equal proportion ($D \approx 20 N$). Modern open-weights models (such as Llama 3 8B trained on 15T tokens, or Qwen3) deliberately over-train smaller models far beyond the Chinchilla ratio (:numref:`sec_scaling-laws`) to amortize training compute against total lifetime inference cost :cite:`Sardana.Portes.Doubov.ea.2024`.
- **Sparse Mixture of Experts.** Building on Top-$K$ noisy gating :cite:`Shazeer.Mirhoseini.Maziarz.ea.2017`, GShard :cite:`Lepikhin.Lee.Xu.ea.2021`, and Switch Transformer :cite:`fedus2022switch`, modern MoE models such as Mixtral 8x7B :cite:`Jiang.Sablayrolles.Roux.ea.2024`, Qwen3 :cite:`Yang.Li.Yang.ea.2025`, and DeepSeek-V3 :cite:`DeepSeek-AI.2024` combine fine-grained routed experts with always-active shared experts :cite:`Dai.Deng.Zhao.ea.2024` and replace or supplement auxiliary load-balancing penalties with dynamic per-expert router biases (:numref:`sec_moe`). Dense checkpoints can also be converted into MoE models via **sparse upcycling** :cite:`Komatsuzaki.Puigcerver.Lee-Thorp.ea.2023`, initializing each expert from the trained dense FFN before continuing pretraining.
