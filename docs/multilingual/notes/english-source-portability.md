# English source portability at PR preparation

A fresh checkout of main does not include generated Quarto files or several retired diffusion chapters. The original validation depended on those local files. This preparation preserves the collection without claiming those historical citations describe the latest book text.

- 102 generated-file references now link to exact passages in a pinned earlier English D2L repository.
- 10 references were matched to inspected tracked Markdown explanations.
- 66 references to removed Markdown chapters now link to the exact earlier Git commit; source bytes were checked against that commit.
- 137 generated-file references retain their path and locator and identify a short captured excerpt in `english-source-excerpts.jsonl`, with original-file SHA-256. They still need current-book citation review. The excerpts make the recorded evidence available without the ignored generated files; they are not independent published attestations.

The validator accepts these explicit excerpt records as available historical evidence. A passing structural check does not establish current-book coverage or semantic correctness. Earlier QA counts and hash comparisons describe the original research snapshot. Term translation statuses and the native-language review queue are unchanged.
